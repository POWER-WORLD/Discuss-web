<h1>📢 Discuss-web-</h1>
A simple and interactive discussion forum website built using HTML, CSS, JavaScript, and PHP.

<h3>🌐 About the Project-</h3>

Discuss-web is a lightweight web-based discussion platform where users can:<br>
<ul>
<li>Create an account</li>
<li>Log in/out securely</li>
<li>Post discussion threads</li>
<li>Comment on existing threads</li>
<li>Search for discussions</li>
<li>Navigate between topics</li></ul>
It mimics a classic Q&A or forum structure, offering a functional demo of web development practices using core web technologies.<br>

<h3>🛠️ Features-</h3>
✅ User authentication (Signup/Login/Logout)<br>
✅ Thread creation and listing<br>
✅ Comments system within threads<br>
✅ Search functionality<br>
✅ Responsive layout<br>
✅ Modular PHP structure (headers, footers, modals separated)<br>
✅ MySQL database connectivity<br>

<h3>📌 How It Works-</h3>

User Registration:<br>
New users can create an account using the signup modal.<br>

Login System:<br>
Existing users can securely log in using their credentials.<br>

Discussion Threads:<br>
Logged-in users can post new discussion topics (threads).<br>

Comment on Threads:<br>
Other users can comment on existing threads to engage in discussions.<br>

Search:<br>
Users can search for specific threads using keywords.<br>

Responsive Navigation:<br>
Easy to navigate pages like Home, About, Contact.<br>

<h3>📑 Setup Instructions-</h3>

Clone the Repository<br>
git clone https://github.com/POWER-WORLD/Discuss-web.git<br>

Set up a MySQL Database<br>
Create a database.<br>
Update p3dbconnect with your database credentials.<br>

Host Locally<br>
Use XAMPP  to run the PHP project locally.<br>

Access<br>
Open your browser and go to http://localhost/Discuss-web/p3index.php<br>
